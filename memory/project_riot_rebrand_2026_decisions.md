Camila's brother Giovanni produced three brand-territory explorations (Urban Core, Anime Fusion, Data Driven) for a Riot rebrand. After a comparison against [[hexagono_de_combate_attributes]] and the CLAUDE.md brand doc, decisions were made:

- **Palette**: keep the current one (black/white/hueso + red accent + cyan for mental attributes). Not migrating to the Data Driven board's blue/teal.
- **Wordmark**: base is "Wordmark Bold" (option 01, from a ChatGPT shortlist) with the slant and diagonal cut of the Anime Fusion wordmark, no kanji. The O must read as O, not D (wider, rounder, oval counter). Earlier "brush style" note was a misreading. Typeface still open.
- **Symbol**: 6-point shuriken-style star built on the hexagon, one point per attribute. Camila likes sketches A (straight points), B (curved) and C (B + faint hexagon + red/cyan tip dots); still needs to pick one. D (radar-shaped) is profile-only. R monogram carries the star top-right.
- **Cyan is kept** (mental attributes, symbol dots), even though the ChatGPT shortlist omitted it.
- **Logo system**: three lockups, no single fixed one — R monograma (profile pics, favicon, small merch details), RIOT wordmark-only (apparel, social banners, simple dojo signage), RIOT BOXING CLUB full lockup (website, formal documents, main dojo signage, Riotdex-equivalent certificates/medals). Camila confirmed this split.
- **Hexágono / combat profile**: shown BOTH ways — real student data (with permission) and brand-concept/illustrated versions. Not an either/or.
- **No AI-generated character illustration**: Camila is uncomfortable with AI-generated anime-style character art as a core brand asset ("me da cosa... no sé si me gusta mucho la idea"). The Anime Fusion territory's illustrated-mascot concept is dropped for this reason, not just a tone-fit reason.
- **Anime quote cards stay**, using real verified anime/manga quotes (screenshot + quote + character name, per [[feedback_anime_quotes_must_be_real]]) — but the visual layout/style can be redesigned to fit the new system.
- **No Japanese/kanji** in the visual system going forward (dropped along with the full manga/streetwear territory).
- **Photo bank**: Camila already has her own real photo bank of the dojo/students and will keep producing more — no gap here.
- **Instagram content mix going forward**: tutorial reels, written-info reels, educational carousels (e.g. "qué es el sparring", "fighting IQ" — a format Riot's Instagram had already run before and is reviving), real photos, testimonials.
- **"Somos gamer" is a core identity confirmation** — not just a content style choice. The actual in-app combat-profile screen (a real screenshot Camila shared) is heavily RPG/gacha-game-coded: rarity tiers (e.g. "RARA"), named archetypes (e.g. "Aplastador" with a flavor line and effectiveness matrix — "Efectivo vs" / "Desventaja vs" against other archetypes, like a fighting-game matchup chart), level + XP bar, "Dominios" per attribute with a "Líder" tag, medals. This is closer to a character-select/gacha profile than a generic fitness-analytics dashboard — stronger differentiator than the "Data Driven" board's corporate-dashboard look, and should anchor the visual direction more than plain "data visualization."
- **Naming note**: CLAUDE.md section 7.5 calls this system the "Riotdex." Camila said as of this conversation "ya no hay Riotdex, ahora aparece diferente" (colloquially calling it a "pokedex" herself) — the in-app name for this screen has changed from what's documented; confirm the current name with Camila before citing "Riotdex" as current terminology.

**Why**: Camila is redesigning Riot's visual identity with her brother Giovanni as the designer; these are the decisions that came out of walking through his three proposals against what's already documented and already built.

**How to apply**: when helping with any future Riot visual/brand asset (logo files, Instagram templates, the combat-profile screen, quote cards), default to these confirmed choices rather than re-opening them. If Giovanni's actual deliverables contradict one of these (e.g. he proposes AI-illustrated characters again, or a blue/teal palette), flag the conflict rather than assuming it's a course change.
