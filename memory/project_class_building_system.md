Riot has an internal app/database for building boxing classes. Each class ("DETALLE DE LA CLASE") has a title format `[SUB-TEMA] - FASE [INICIAL/1/2/3...]`, a date ("Todo el día"), and three fixed blocks:

1. **Calentamiento**: short warmup, exercises tagged by attribute worked. For Fuerza-focused classes it's 4 exercises of 1 minute each (kept short/non-fatiguing since the session is power-focused). For other attributes (seen with Astucia) it can be 3 exercises of 1-2 min with circuit format (e.g. 60/15s).
2. **Base**: always boxing-technique drills (never generic fitness), in pareja, that build the specific motor pattern needed for that phase's skill. These repeat across the phases of the same thread (e.g. "Amague simple en paragolpes" / "Cambio de ritmo en paragolpes" repeated across Astucia-Provocaciones Fase 1 and Fase 3).
3. **Boxeo**: application block. Usually opens with **"Pokebola Standard"** — a rotating live-sparring drill ("Un [alumno] pelea con cada alumno de la clase, uno tras otro", 2 min por pareja, 25 seg descanso) — followed by specific paired drills. Paired drill descriptions use **rojo:** (the student executing the taught action) and **azul:** (the partner reacting/receiving) to define roles. Complexity escalates by phase (Fase 1 = simple bait/cebo drills; Fase 3 = combined/multi-stage drills with "Fase inicial / Fase intermedia" sub-steps inside one exercise).

**Curriculum ("temario") structure**: each of the 6 hexágono attributes (Fuerza, Destreza, Inteligencia, Astucia, Resistencia, Percepción — see [[hexagono_de_combate_attributes]] if that memory exists) breaks into 5 sub-skill bullets from its own definition (e.g. Astucia = Engaños, Cambios de ritmo, Provocaciones, Trampas tácticas, Creatividad bajo presión). Each sub-skill becomes its own **class thread** that runs across multiple dated classes, escalating Fase Inicial → Fase 1 → Fase 2 → Fase 3...

**Equipment on hand for physical/Fuerza work**: pesas, discos, barra olímpica, saco, pera loca, cajón (plus other unlisted items).

**Why**: the user is building out a curriculum for the Fuerza attribute (started 2026-07-20) and needs new classes to match the exact format/granularity already used for Astucia so they slot directly into the existing database/app.

**How to apply**: whenever asked to build clases or temarios for Riot, always output in this exact 3-block structure (Calentamiento/Base/Boxeo), follow the sub-thread-per-attribute model with phased escalation (thread count varies by attribute — verify against the attribute's actual card, see [[hexagono_de_combate_attributes]]), and format paired application drills with rojo/azul role descriptions. Don't invent structure — ask for the equipment list or existing exercise bank for a given attribute if unknown, same as was done for Fuerza.

Destreza Calentamiento is a **fixed set of 4 exercises every class**, 1 min each x 15 seg descanso, where each exercise's difficulty escalates week-to-week ("todo ejercicio va de menos a más") rather than rotating between different exercise sets:

Together these 4 touch all 6 sub-habilidades every single class — no rotation needed.

Equipment on hand for Destreza: barras olímpicas, mancuernas, kettlebell, escalera de agilidad, elásticos, loops, aros, saco, pera de velocidad, conos, lentejas, discos.

**Progression methodology (also saved to CLAUDE.md section 7.7)**: 1) aislar el movimiento (mecánica pura, sin velocidad/reacción, repetición-repetición) → 2) agregar UNA capa de dificultad a la vez (cambio de guardia, golpe, combinación suave, punto de referencia físico como cono/cuerda/lenteja) → 3) tender hacia el combate. Applies to any attribute/sub-habilidad, not just Destreza.

**Weekly scheduling reality**: the dojo runs 4 physical classes/week but only 2 distinct contents are designed — Lunes=Martes (same content), Miércoles=Jueves (same content). So each "Día 1"/"Día 2" designed class actually covers 2 real dojo days. A week can be spent on ONE sub-habilidad (both designed days go deep on it — this is what happened with Técnica) or SPLIT across TWO sub-habilidades (each gets one designed day) — splitting works best when pairing a fresh sub-habilidad with one that already has a banked/reusable exercise set, so design effort concentrates on the new one.

**Destreza curriculum — CLOSED/COMPLETE as of 2026-09-06** ("cerramos mes de destreza"). Final structure, all 6 sub-habilidades:
- **Técnica** — 2 classes/1 week. Día 1 = torso rotation mechanics (torsión con elástico anclado, golpes con disco en pecho, elástico cruzado, torsión al saco). Día 2 = leg/pivot mechanics, static/repetition not combat footwork (pivote pie atrasado con lenteja + cambio de guardia + golpes, pivote pie adelantado con cono, esquive corto con cuerda entre postes + golpe, "Telaraña" — vendas entrelazadas + burpees + esquives/rolls/pasos cortos + combinación suave).
- **Juego de pies** — reused an existing exercise bank from a prior dedicated month (entries like "Paso fantasma", "Zig Zag con cruzado + galope", tagged duración/individual-pareja/guardia). No new design needed.
- **Coordinación** — 1 class only (repeated for the week). Confirmed complete, exact final exercise list not re-confirmed in detail in this session (was drafted as: patrón cruzado mano-pie aislado, golpe + paso desfasado, doble estímulo visual/sonoro, combinación con cambio de guardia — user said "está listo" without walking through edits, so treat as close to that draft but verify in the app if precision matters later).
- **Precisión de golpeo** — 1 class, 4 exercises: golpes en aro (trayectoria), toque de lenteja (blanco chico), elástico fijo (precisión bajo resistencia/rotación), pelota soltada al azar (reacción + precisión).
- **Fluidez de movimientos** — 1 class, 5 exercises: cruzado x cruzado con roll (pareja, alternando + variante de cambio de guardia), ganchos alternados con base marcada, "traspaso de peso en ola" (cruzado y cruzado con transferencia de peso lateral), jab-esquive/derecho-esquive fluido, jab + bloqueo de antebrazo + contragolpe recto (con variante de cambio de guardia).
- **Defensa por esquiva** — 2 classes, redesigned mid-session to be advanced/reactive (see student-level note below). Día 1: esquiva reactiva sin patrón, esquiva con amague mezclado, esquiva + combinación de contragolpe, esquiva bajo presión de 2 compañeros. Día 2 (user's final version): golpes solitarios + esquive de piernas + contra fuerte; combo de 3 suaves + salida + contra fuerte; combo de 3 (cierre cruzado) + roll en el último; mismo + salida post-roll; sparring suave defensa pura; mismo round con contra.
- **Conclusión (cierre de mes)** — new structural pattern: a capstone class of themed live rounds (~1-1.5 min c/u, 25s descanso, Pokebola-style), one round per sub-habilidad, each imposing a real-combat constraint tied to that skill instead of an isolated drill. Round 2 (Coordinación) first drafted as "cambiar de guardia durante el round" but rejected as too easy — replaced with an external random-signal-with-preassigned-response task performed mid-fight (e.g. palmada = cambio de guardia, número par = doble jab), since switching guard alone is already automatic for these students. **This "Conclusión" capstone is a reusable pattern — apply it to future attributes' month-end too, not just Destreza.**

**Student level — important, applies beyond Destreza**: these are students with 2-4 years of experience, some actively competing. Revealed mid-session while building Defensa por esquiva, which had to be redesigned from basic/isolated drills to reactive, unpredictable, live-pressure drills once this came up. **For future attributes, default to this experience level (advanced/competing) for Boxeo-block content — don't default to beginner-isolated drills unless the user specifically asks for fundamentals reinforcement** (as happened with Técnica, where the user explicitly asked to shore up giro de cintura/pivotes despite the group's experience — that was a deliberate exception, not the norm).

**Lesson**: don't invent a full exercise system speculatively when the user hasn't provided a bank — ask first, or clearly flag drafted content as a placeholder pending confirmation. The user corrected the Calentamiento draft immediately with their real exercises. Same pattern repeated later with Defensa por esquiva Día 2 — draft first, expect the user to hand back their own final version, format it cleanly rather than assuming the draft survives untouched.
